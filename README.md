# 微信伴侣 · 一个有生活的 AI

她是一个有性格、有作息、有自己日子的 AI，住在微信里跟你聊天。

**她不是自动回复机器人。** 每天晚上你睡着之后，她会跑一次「世界引擎」，替自己写下明天要过的日子 —— 几点起、几点睡、什么心情、今天干了什么、心里藏着什么小秘密。第二天你跟她聊天时，这些会自然地冒出来。

---

## 她能做什么

- **有性格** —— 六维人格（从 MBTI 推导），说话方式、反应快慢、话多话少都由性格决定。被凶了当天会真的变冷，第二天回落
- **有自己的生活** —— 作息、心情、天气、一天干了什么，是"过"出来的，不是每次现编
- **会主动找你** —— 早安晚安、太久没聊会想你；但刚聊完绝不打扰你
- **记得住** —— 长期记忆 + 遗忘曲线。重启不失忆，聊得越久记得越多
- **看得懂图** —— 你发图片给她，她看得见
- **会发表情包和照片** —— 说话时顺手带一个，文字和图片一起发给你
- **答应的事会记着** —— 到点自己提，每条只提一次
- **会连发消息** —— 拆条发送、打字延迟、"对方正在输入…"，像真人一样
- **称呼会变** —— 聊熟了她自己决定怎么叫你，不是你设定的
- **复读会止血** —— 判到重复就换一件事说，换不出来这条就不发
- **想念有曲线** —— 14 小时最想你，三天后各自过日子；重逢只提一次
- **她眼里的你** —— 不是"他住南京"，是"他不太习惯说自己累"
- **睡着了不打扰** —— 有作息，不是每条都回

## 快速开始

**前置条件：Node.js 20 或更高**（[下载](https://nodejs.org/)）。终端里 `node --version` 显示 20 以上就行。

**不需要 `npm install`** —— 本项目零依赖，没有 `node_modules`，拉下来就能跑。

```bash
npm run doctor    # 1. 体检：环境、网络、配置逐项检查
npm run login     # 2. 扫码绑定微信（终端里出二维码）
npm start         # 3. 启动她
```

启动后打开控制台：**http://127.0.0.1:43121/**

第一次用建议先跑 `npm run once` —— 不连微信，直接看她的系统提示词和一次真实回复长什么样。

### 需要准备的只有一样：一个模型 API Key

任何 **OpenAI 兼容接口**都能用 —— 官方站、中转站、本地 Ollama 都行。在控制台「大脑」页填 `baseUrl` + `Key` + 模型名，填完点「测连通」，再点「真跑一次」，两个都绿了就能用。

> 建议挑**角色扮演能力好**的模型。这个项目的成败几乎全在"她像不像人"，而不是模型有多聪明 —— 太小的模型会答非所问，推理型模型回复偏慢。

## 控制台

启动后打开 http://127.0.0.1:43121/ ，共 8 个页签：

| 页签 | 管什么 |
|---|---|
| 首页 | 运行状态、今天的她、试聊 |
| 她是谁 | 名字年龄职业背景、性格、说话方式、兴趣 |
| 大脑 | 对话模型、世界引擎、测连通、真跑一次 |
| 她的世界 | 手动跑世界引擎、看明天的剧本、翻她的日记 |
| 记忆 | 她记得的事 |
| 相处 | 回复速度、拆条数、手滑概率、急停、主动消息 |
| 工具 | 让她发照片、写朋友圈文案、看路径 |
| 日志 | 最近 200 行 |

**急停开关**在「相处」页 —— 勾上她立刻不回复任何消息。

**配人设不用填一堆字段**：「她是谁」页写一段大致描述就行，比如"她叫阿梨，26岁，在成都做插画师，话不多有点慢热，喜欢猫和下雨天"，点「生成人设」会自动补全剩下的，**你看过再点保存**。

## 数据都在这个文件夹里

```
data/
  config.json     她的设定、模型、通道绑定（含密钥，别外传）
  memory.json     她记得的事
  world.json      世界引擎写的剧本
  companion.log   运行日志
  diary/          她的日记（按天一个 .md，记事本能直接打开）
  inbox/          收到的图片和文件
  photos/         她的相册
```

**整个文件夹可以整体搬走** —— 路径不写死，不依赖注册表或用户目录，搬到别的盘、拷到服务器都能跑。

**她的相册怎么用**：把真实照片放进 `data/photos/`，文件名写清楚内容（比如 `团子在窗台.jpg`）。文件名就是她"看到"的东西，她会配一句话发给你。

## 命令

```bash
npm start            # 启动她（常驻，带控制台）
npm run login        # 扫码绑定微信（终端里出二维码）
npm run login:gui    # 扫码绑定（二维码存成图片打开，更好扫）
npm run doctor       # 体检：环境、网络、配置、模型逐项检查
npm run once         # 干跑：不连微信，看提示词和一次真实回复
npm run fetch:stickers   # 装一批现成的表情包（99 张）
npm test             # 核心单元测试
npm run test:all     # 全部测试套件
npm run pack         # 打包给别人（自动拦截密钥）
```

**测试不会碰你的真实数据** —— 跑之前会把 `data/` 拷一份到 `.test-data/`，全部测试在那上面跑，跑完删掉。

## 搬到服务器

程序不写死任何路径，整个文件夹拷走就能跑。建议用 pm2 常驻：

```bash
npm i -g pm2
pm2 start src/main.js --name wechat-companion
pm2 save && pm2 startup      # 开机自启
```

> ⚠️ 控制台默认只监听 `127.0.0.1`，**不要**暴露到公网 —— 它能改她的一切设定，而且没有认证。要远程看，用 SSH 隧道：
> `ssh -L 43121:127.0.0.1:43121 user@server`

## 声明

### 安全性

她走的是**微信 iLink 官方机器人通道**（也就是俗称的 "clawbot" 用的同一套后端协议）：

- 纯 HTTPS + Bearer token
- 不注入微信进程、不修改内存、不模拟鼠标点击
- 不登录你的个人微信号

**但请仍然注意**：自动化操作微信属于违反微信软件许可协议的行为，账号风险需要你自己评估。建议用小号、保持低频（程序默认已经是拟人节奏，每日主动消息有上限）。

### 做不到的

- **发朋友圈、朋友圈点赞评论** —— 微信个人朋友圈没有公开协议，官方机器人通道也没有入口
- **发语音条** —— 通过官方机器人通道发不出

替代方案：朋友圈文案她会私聊发给你；想让她发照片，把图放进 `data/photos/`。
